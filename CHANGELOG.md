# Changelog

All notable changes to ChatGPTCleaner are documented here.

## [1.0.0] - 2026-10-12

### Added

- Initial public release for filtering, sorting, selecting, protecting, and bulk-deleting standalone conversations.
- Complete Project conversation discovery and exclusion from destructive planning.
- Explicit confirmation followed by a lock-protected, sequential deletion workflow with rate limiting, retries, Pause, Resume, and Stop.
- Production GitHub Release packaging and isolated demo/debug development modes.
