# Contributing to ChatGPTCleaner

Issues and feedback are welcome, including bug reports, reproducible failures,
compatibility reports, feature suggestions, and UX feedback. Report security
issues through the process in [SECURITY.md](SECURITY.md).

ChatGPTCleaner does not currently accept third-party pull requests containing
copyrightable contributions for merge. This includes application code, tests,
documentation, translations, graphics or other assets, and other authored
project material. Please open an Issue instead to report a problem or suggest a
change.

Opening an Issue or pull request, or offering a suggestion, does not transfer
rights or make the submission or suggestion project property.
